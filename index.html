Where your key goes

        
    
          
  • This page has no server. Your key is kept in this browser tab, or in this browser's storage if you choose to remember it.
    • 
          
  • The page's security policy only allows network requests to Anthropic's API, so the key can't be sent anywhere else by this page.
    • 
          
  • Templates, conversations and your key are never saved to GitHub. Export your workspace to back up templates and conversations; the export never includes the key.
    • 
          
  • Use a key you created just for this tool, with a spending limit set in the Anthropic Console, and delete it when you're done testing.
